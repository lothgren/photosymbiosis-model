# endosymbiosis-model
Underlying code for the endosymbioisis model as part of the PhD project

The repository is structred as follows:

### model.py
Contains the ODE function for model of project, endo(), as well as symbolic version.

### analysisTools.py
Contains tools used to analyse the model, e.g. simulating, finding fixed points, creating bifurcation diagrams etc.

### analysis.py
Script where the tools are used to analyze the system and create plots
